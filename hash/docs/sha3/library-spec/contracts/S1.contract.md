## Adequacy and satisfiability

An always-empty encoder fails all-bytes spelling. A coupled reversed codec
can pass round-trip but fails canonical spelling. A permissive decoder fails
uppercase/odd/Unicode cases. A fixed-empty digest fails width and the three
nonempty CAVP rows. A fixed Len=0 digest fails the other rows. A CLI that
decodes text rather than reading raw bytes fails the binary CAVP fixture.
These witnesses use valid `UInt8` ranges, byte widths, and the exact existing
CAVP literals; no expected digest is independently retyped. No prose wording
equality or additional stage timing requirement is added.
