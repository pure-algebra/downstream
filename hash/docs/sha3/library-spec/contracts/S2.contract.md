## ENSURES — declared algebraic degree

The formal degree is the universal A1.S2 refinement spine, ending at
`sha3_512_eq_impl`, then the unchanged API specification theorem. Runtime
tests are executable falsifiers, not proofs of universal conformance or
security. Compiled behavior, performance, and compiler/IO seams remain
observations outside the theorem claim.

Let `L(bs) = bs.data.toList`, `A(s) = Fast.abs s`, and
`B(bs,off) = (L(bs).drop off).take 72`.

| Law | Equation | Falsifier / executable witness family |
|---|---|---|
| F2.1 native rotations | `(rotl x n).toBitVec = x.toBitVec.rotateLeft n` for `n < 64` | all 64 shifts of 0, 1, high-bit, all-ones, asymmetric lanes; zero and 63 explicit |
| F2.2 tables | every RC and rho entry equals Impl's corresponding entry | all 24 / 25 entries; not only entries reached by one chosen state |
| F2.3 round steps | `A(op s) = Impl.op (A s)` for theta, rhoPi, chi, keccakF; same for every rnd index | zero, all-ones, asymmetric states; 24 round indices; mismatch at any lane fails |
| F2.4 byte addressing | `byteAt bs i = L(bs).getD i 0` | lengths 0, 1, 7, 8, 71, 72, 73; in/out-of-range reads |
| F2.5 lane addressing | `(laneAt bs off i).toBitVec = Impl.laneOfBytes (L(bs).drop off) i` | nonzero offsets, partial lanes, beyond-end offsets, lane 9 on a multi-block buffer |
| F2.6 block footprint | `A(absorbBlock s bs off) = Impl.absorbBlock (A s) B(bs,off)` | full-buffer capacity leak: `bs = 72 zero bytes ++ [1]`, offset 0, plus changed prefixes and suffixes |
| F2.7 absorb fold | `A(absorbAll bs) = Impl.absorbAll L(bs)` | all lengths 0..160 and selected larger block boundaries; incomplete suffix ignored |
| F2.8 padding | `L(padBytes bs) = Impl.padBytes L(bs)` | every residue mod 72, exact multiples, one-byte-pad branch |
| F2.9 squeeze | exactly 64 bytes, lanes 0..7 little-endian, equal to Impl squeeze | patterned/all-ones states; first/last byte ordering and length |
| F2.10 native apex | `L(Fast.sha3_512 bs) = Impl.sha3_512 L(bs)` | all lengths 0..160, plus 215..217, 287..289, 511..513, 1024; varied bytes |
| F2.11 API retarget | `(Hash.Sha3.sha3_512 bs).bytes = Fast.sha3_512 bs` definitionally; public statements unchanged | compile `Signatures.lean`; runtime API versus native bytes |
| F2.12 evidence and speed | all inherited gates green; native call graph has no computational Impl path | inherited build/audit/checker/consumer gates, source review, and §Performance protocol |

F2.6 is essential: `laneAt` deliberately reads the whole available suffix,
whereas `absorbBlock` must inject only nine rate lanes and leave capacity
lanes unchanged before permutation. Using `laneAt bs off i` for all 25 lanes
is incorrect when bytes from the next block exist. The public SPEC has no
named `absorbBlock_abs` theorem, so this equation is an implementation helper
obligation and a runtime falsifier, not a change to A1.S2.

## DECREASES

Permutation folds consume 24 rounds; lane packing consumes 8 bytes;
absorption consumes `P.size / 72` block indices using `Nat.fold`; squeeze
consumes 64 output bytes. Structural recursion or bounded folds only.

## FRAME

Writes: new `Hash/Sha3/Fast.lean`; `Hash/Sha3/Api.lean` native retarget and three proof
bodies; root import; existing Verified audit-count pin; README native
description and measured timings (C-2). `Gates/Sha3.lean` is unchanged.
No consumer migration, dependency change, network fetch, commit, or push.

buffer, prefix before `off`, and suffix after the rate block are unaffected.

   `git diff --stat` are recorded. No commit.
